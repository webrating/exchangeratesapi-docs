## Overview

Registers a webhook subscription. The response includes a **signing secret shown only once** — store it securely; you'll need it to [verify deliveries](/api-reference/webhooks/overview#verifying-signatures).

<Note>
Webhook subscriptions are created and managed from your **dashboard** (authenticated session), not with a Bearer API key. Professional plan or higher is required.
</Note>

`currencies` is optional — omit it to receive every supported currency, or pass a list (e.g. `["USD","JPY"]`) to receive only those. The `url` must be a public **HTTPS** endpoint.
